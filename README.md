# yazveciz.com ürün bulucu

Bu depo yazveciz.com'daki "Sana uygun kalemi bul" aracının yayın dosyalarını barındırır.
Dosyalar mağazanın ikas paneline eklenen küçük yükleyici tarafından jsDelivr üzerinden, sabit commit
adresi ve SRI (sha384) mührüyle yüklenir.

- `bulucu-vN.js`: herkese açık sürüm
- `bulucu-vN-test.js`: test sürümü (yalnızca `?bulucu_test=1` ile açan tarayıcıda çalışır)

Dosyaları elle değiştirmeyin veya silmeyin. Yeni sürüm her zaman yeni bir dosya adıyla eklenir.
